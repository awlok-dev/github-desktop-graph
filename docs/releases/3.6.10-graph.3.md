Windows x64 portable build based on GitHub Desktop 3.6.10.

- Compact graph spacing: 10-pixel lanes and 28-pixel rows by default. Turn off
  **Compact** for more space.
- Fix horizontal scrolling so wide graphs no longer hide commit and branch details.
- Show additional branch and tag labels through **+N**, with the same Git actions
  in each branch's submenu.
- Provide clearly labeled **Side by side**, **Swipe**, **Onion Skin**, and
  **Difference** image comparisons in the commit changes pane.
- Start onion skin at 50% opacity and provide a keyboard-accessible opacity slider.
- Preview historical SVG changes, including added, renamed, and deleted images.
- Fit image comparison controls to the lower pane and hide irrelevant text diff options.

Download **GitHubDesktopGraph-Portable-Windows-x64-3.6.10-graph.3.zip**,
extract the entire ZIP, and run **GitHubDesktopGraph.exe**. No installation,
Node.js, or separate Git installation is required. A SHA256 checksum is included.

To upgrade, close the old app and copy its **Data** folder beside the new executable.
Repositories can stay at their existing paths.

Verified using a graph with 64 lanes and 41 labels on one commit, image comparisons,
and real Git operations in the packaged app. Tested on Windows 10 and a GitHub-hosted
Windows runner. Windows 11 and future Windows versions have not been directly tested.
This is an unsigned community build.
