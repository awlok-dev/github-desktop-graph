Windows x64 portable build based on GitHub Desktop 3.6.10.

- Show the selected graph commit's changed files and diff in the bottom pane.
- Select a file to inspect additions, deletions, renames, images, or binary changes.
- Resize the file list and choose unified/split diffs or hide whitespace changes.
- Inspect commits on any branch without changing the checked-out branch.
- Handle empty commits and discard outdated loads when switching commits quickly.
- Keep Copy SHA and View on GitHub in the commit's right-click menu.
- Retain the working Graph tab and branch actions from graph.1.

Download **GitHubDesktopGraph-Portable-Windows-x64-3.6.10-graph.2.zip**,
extract the entire ZIP, and open **GitHubDesktopGraph.exe**.
Electron, Git, and Git LFS are included; no installation or separate Node.js/Git
installation is required. The `.sha256` asset provides the ZIP checksum.

To upgrade, close the old app and copy its **Data** folder beside the new
executable. Keep your repositories at their existing paths.

Targets Windows 10/11 x64. This is an unsigned community build, verified on
Windows 10 and a GitHub-hosted Windows runner. Windows 11 and future Windows
versions have not been directly tested. GitHub account sign-in is inherited
from upstream and is not exercised by the local-repository smoke tests.
