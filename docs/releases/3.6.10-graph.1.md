Windows x64 portable build based on GitHub Desktop 3.6.10.

- Fix the unresponsive Graph tab by giving Graph its own repository section.
- Display all branches and merge connections with a virtualized commit list.
- Right-click branch labels to checkout, push, pull, fast-forward, merge, or rebase.
- Fix merge setup and prevent push/pull if a preceding checkout was cancelled.
- Keep settings beside the executable and disable upstream automatic updates.
- Include Electron, Git and Git LFS: no installation, Node.js, or separate Git required.

Download the **GitHubDesktopGraph-Portable-Windows-x64-3.6.10-graph.1.zip** asset,
extract the entire archive, and open **GitHubDesktopGraph.exe**. The `.sha256`
asset provides its checksum. Source code archives are not runnable apps.

Targets Windows 10/11 x64. This unsigned community build is tested with a packaged
application smoke test and real Git operations against temporary local remotes.
Future Windows versions and every hardware configuration are not certified.
GitHub browser authentication is inherited from upstream; the smoke test uses
local repositories and does not exercise account sign-in.

To upgrade, close the old app and copy its **Data** folder into the extracted
new application folder. Keep your repositories at their existing paths.
